「フォルダを選択」で、このページのあるフォルダ Meridian_LITE_for_ESP32 (./) を選ぶと、
そこからの相対パス (既定: src/config.h, src/keys.h) のファイルを読み込みます。
その親フォルダを選んだ場合は、中の Meridian_LITE_for_ESP32 を自動で使います。
初回だけブラウザが読み書きの許可を求めます。

Chrome / Edge で開いてください。その他のブラウザでは、ファイルを開いてダウンロード保存する方式になります。
Press "Select folder" and choose the folder of this page, Meridian_LITE_for_ESP32 (./).
The files at the paths relative to it (default: src/config.h, src/keys.h) are loaded.
If you choose its parent folder, Meridian_LITE_for_ESP32 inside it is used automatically.
The browser asks for read/write permission the first time only.

Open this page in Chrome / Edge. Other browsers open the file and save it as a download.
